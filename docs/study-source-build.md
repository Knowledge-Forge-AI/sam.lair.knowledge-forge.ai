# Personal study source build

The normal package build is source-owned and repo-relative:

```text
npm run build
npm run test:study-source
```

`npm run build` invokes `tools/build-study-source.mjs` and then the local
`astro` executable. The generator imports the vendored study-components
MDX/semantic
subpaths and the installed MDX/math/React packages. It does not import a
second checkout, use an absolute tool path, or borrow another Astro closure.

The generator reads the maintained lesson MDX, Python source, provenance,
terms, and license files; validates their source hashes and license labels;
compiles the MDX into the semantic static lesson; regenerates
`src/study/generated-study.js`, the published provenance record, KaTeX CSS,
the 60 KaTeX font files, and the KaTeX MIT notice; and records hashes in the
ignored `build/study-source-binding.json` receipt. Before any derivative is
written, the generator preflights every owned path and ancestor, checks the
previous output-lock/binding hashes, and refuses tampered regular files,
including dangling leaf/ancestor symlinks, directories, special files, stale
font entries, and unexpected output-set changes.
With no prior ownership record, an existing derivative is accepted only when
it is already byte-identical to the newly generated bytes. The generated
paths are listed in `.gitignore` with the generator as their owner.

The optional editor is deliberately generated as a disabled static seam. No
Python assets, browser runner, editor runtime, or interactive control is
activated by this build. Mathematical correctness and runtime behavior are
not claimed.

The focused test checks the exact baseline direct dependency values and every
non-root baseline lock entry, the recorded lock top-level fields, 44 HTML
pages / 145 output files, source-linked MathML/proof/code markers,
legal/provenance links, generated asset hashes, private-output scanning,
authored heading preservation, tampered derivative refusal, dangling
leaf/ancestor refusal, unchanged rebuilds, and a valid source-change
rebuild/restore cycle.
The lock top-level name is asserted as `knowledge-forge.github.io`, matching
the public baseline lock blob; the root `package.json` name remains empty as
in that baseline.
The portable baseline fixture is inside `test/fixtures/`; it contains only
hashes, headings, dependency values, and the explicitly admitted lock-entry
paths, never a private checkout path. The intentional site-shell delta is one visible Study link to
`/study/lehman-ch3-p4/`; no landing page is added.

The exact public projection is recorded by the explicit path list in
`test/fixtures/study-baseline.v1.json` and described in
`docs/study-public-manifest.md`. The focused test reads only those listed
regular files; it does not walk the checkout, read Git objects, or inspect
unknown ignored/local paths. The verifier source is included in the list but
excluded from the aggregate to avoid a self-hash cycle. A fresh-clone fixture
with Git metadata and an ignored `.DS_Store` is checked separately.

The baseline source and selected Lehman material retain their existing
attribution and license split. The GPL-3.0 source label remains distinct from
the AGPL package license, and the KaTeX MIT notice is copied from the exact
installed KaTeX package. No Goodrich material is included.
