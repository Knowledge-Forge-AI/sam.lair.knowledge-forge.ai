# Study source build and optional Python pilot

Run `npm ci --ignore-scripts`, `npm run build`, then `npm run test:study-source`.
The portable generators compile maintained MDX, semantic proofs/references,
truth tables and source-code includes. Existing derivative ownership, drift,
symlink and source-change checks remain required. The three lessons retain
their individual provenance, attribution and content/code terms.

Lehman Chapter 3 Problem 4 also offers a lazy React/CodeMirror editor. Its
draft and undo history belong to the parent UI. Run initializes the separate
`https://study-runner.knowledge-forge.ai` frame; Python assets are not part of
this site and are not loaded while reading static lessons. The frame accepts
the fixed personal-site origin. Stop and the external deadline dispose the
execution context; errors must preserve edits. Goodrich, Rosen and ordinary
articles remain static and load no language runtime.

The consumer pins the five optional CodeMirror peers and their locked MIT
closure. Notices are retained at `/study/licenses/codemirror-NOTICES.txt`.
The dist-only vendored study package projects the accepted private.1 source,
removing only source-development dependencies as in its private.0 predecessor.
All runtime modules, declarations, optional peers and legal texts are retained.
No compiler, Python interpreter or provider credential is added to this site.

The build/test proves source fidelity, output ownership, prior headings,
locked dependencies and static semantics. It does not prove mathematical
correctness, browser execution, hard memory isolation or a cookie-free origin.
Real-host execution and browser lifecycle checks are separately recorded.
Rollback reverts the island, vendor projection and the five direct pins plus
their exact new lock entries together; the static lessons remain usable.
