I started Agentic Praxis Grimoire with six recurring engineering jobs: bounded assignments, design, planning, implementation, debugging and review. I wanted each practice to explain when it helps and when it should stay out of the way.

## What this release means to me

The useful unit, for me, is a practice with a boundary. A longer instruction file is easy to produce; a procedure that knows when to stop is a more interesting engineering problem.

## The release boundary

The first public version includes discovery and adoption tooling that respects existing repository content. Its bootstrap scenarios and early dogfooding are a foundation for bounded experimentation, not proof of automatic skill selection or a production warranty.
