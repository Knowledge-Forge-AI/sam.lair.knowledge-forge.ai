With APGR 0.13.0, I made the single-phase dispatcher independently usable and gave its operator home an explicit layout. Review mutation controls and observations make more of the execution boundary inspectable.

## What this release means to me

The adaptive context experiment remains opt-in, and I am not claiming measured token savings. The published release establishes release identity; earlier candidate notes are not a final report that every distribution channel has completed.

## The release boundary

Optional RTK integration, operational observations and a first-party Nix surface accompany the runtime work. Static transport remains the default. The catalog reaches forty-six skills without a maturity promotion.
