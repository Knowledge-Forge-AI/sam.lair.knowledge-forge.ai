With Nebular 0.8.0, I connected paired-v2 authoring to Solar Sail and Stellar Loom previews, candidate exchange, review and persistent drafts. I wanted the workbench to connect the engines while keeping each input and result inspectable.

## What this release means to me

The application also gains six light/dark appearance families and independent mode preferences. Apple Silicon now requires macOS 13.3; Linux uses system WebKitGTK. The macOS developer application is not represented as notarized.

## The release boundary

The release links source and native qualification, including persistence/reopen and appearance cases. System/Light/Dark behavior, independent family preferences for each mode and reset to bundled defaults are application settings rather than a static interface proposal.
