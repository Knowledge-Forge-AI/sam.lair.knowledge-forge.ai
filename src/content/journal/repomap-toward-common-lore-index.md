I am working toward the name Common Lore Index, or CLOE, for the project currently published as RepoMap. The idea is still a concrete one: make the relationships in a repository navigable, with facts linked to source evidence.

## What this milestone means to me

DINAS was the original inspiration. I needed to understand how a modular workstation fit together, then turned that need toward reusable repository analysis. The rebrand is in progress; it does not rename the installed CLI, Python imports or package today.

## The release boundary

The public project is still working through pre-v0.1.0 product gates. Its roadmap distinguishes Local, Server Engine and Cloud surfaces. A roadmap target does not establish availability; current project documentation owns the supported setup.
