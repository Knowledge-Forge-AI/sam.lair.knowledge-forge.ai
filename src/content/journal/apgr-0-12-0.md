APGR 0.12.0 takes ownership of the single-phase runtime previously housed in Agent-Central. That puts structured request execution and its durable result alongside APGR’s public domain packages.

## What this release means to me

For me, this is an ownership milestone. A toolkit becomes easier to integrate when its runtime responsibilities live with the public interface, while callers still retain their own policy and orchestration decisions.

## The release boundary

Request V2 execution, persistence, rerouting, result repair and explicit Git finalization sit beside the public Go packages and JACA XO integration surface. The forty-five-skill corpus receives no maturity promotion. Registry completion remains separately recorded from GitHub asset attachment.
