I added GoMock, Vitest, JSX, React, MDX and Astro profiles in APGR 0.6.0. The point is to help with the specific seam a task crosses, without making every frontend question trigger a compulsory tour of the whole stack.

## What this release means to me

I kept the six additions provisional and retained a real locked-install stop in qualification. An unmet prerequisite is part of the evidence, even when preserving it makes the release story less tidy.

## The release boundary

The catalog reaches thirty-nine skills. Project-selected projection remains authoritative; this version introduces neither automatic nor advisory profile selection. Qualification exercises web and Go compositions without creating an aggregate owner for an entire stack.
