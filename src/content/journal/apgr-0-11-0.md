I added the Knowledge Forge AI Homebrew tap to APGR’s distribution story in 0.11.0. The supported targets remain Apple Silicon, Linux AMD64 and Linux ARM64; this release does not add Intel macOS.

## What this release means to me

A formula, a binary and a native consumer are connected artifacts, but they answer different questions. I want an installation route to state what was qualified rather than borrowing confidence from a checksum alone.

## The release boundary

The release retains forty-five skills: fourteen stable and thirty-one provisional. Homebrew availability does not promote those skills or erase the recorded CSS and JavaScript qualification debt.
