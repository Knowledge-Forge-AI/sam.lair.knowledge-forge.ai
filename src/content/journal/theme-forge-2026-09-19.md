I introduced Solar Sail 0.1.0 for Tailwind CSS v4 and shadcn/ui. It adds another target to Theme Forge while retaining a deterministic compiler, a library interface and a command line.

## What this release means to me

I want the same design conversation to reach different systems without pretending their integration contracts are interchangeable. A documentation theme, a Tailwind compiler and a desktop app each need their own installation instructions.

## The release boundary

Loom 0.3.0 adds reading-layout presets, distribution-safe TypeScript emission, Expressive Code styling and book-chrome navigation. Nebular 0.4.0 repairs Scene resource and sidecar timeout contracts; Terminal Nova 0.3.0 supplies its theme-package provenance.
