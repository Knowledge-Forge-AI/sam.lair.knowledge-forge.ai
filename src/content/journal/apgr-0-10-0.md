APGR 0.10.0 adds profiles for SVG, Playwright Test, accessibility, Vite, npm and browser behavior. I wanted the catalog to cover more of the questions that appear between source code and a working page.

## What this release means to me

Having an accessibility profile does not establish accessibility, any more than having a test profile establishes that a test ran. I want the guidance to sharpen judgment while leaving the proof with the actual project.

## The release boundary

The catalog reaches forty-five skills. Persisted-report verification checks accepted records without repairing source; operational records gain semantic validation, and opt-in idempotency distinguishes an exact retry from conflicting content. Recorded JavaScript qualification debt remains visible.
