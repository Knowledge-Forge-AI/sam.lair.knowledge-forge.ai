I gave Terminal Nova six appearance families across its Starlight and Tailwind/shadcn targets: Terminal Nova, Nebular, Developer, Graphic Designer, Anime and Gamer, each in light and dark.

## What this release means to me

Shared foundations should leave room for a project to have its own character. These releases freeze the package outputs; registry publication and demonstration-site deployment remain separate steps from creating the GitHub release.

## The release boundary

STTN 0.5.0 carries the Starlight styles; CTTN 0.2.0 exposes the shared catalog and generated CSS. CTTN qualification spans Apple Silicon and both Linux architectures, while STTN checks its installed-package demonstration and existing theme surface.
