I made the first DINAS Browser UX preview public as a source snapshot. It exposes baseline policy, command sources and scrollbar presentation work so the interfaces and their composition can be studied.

## What this release means to me

I am keeping the claim at that boundary: source preview. It is not an installed extension, a native browser acceptance result or proof that an entire workstation configuration is ready to activate.

## The release boundary

Synthetic fixtures and source-level checks accompany the code. The repository preview version is separate from the scrollbar extension source version, and this event publishes neither binary assets nor registry packages.
